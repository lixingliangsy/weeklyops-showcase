# Weekly Ops Report

> Your weekly ops report, generated by four AI agents — delivered as Excel.

**Category:** Data & Analytics

**Live product:** [https://weeklyops.lxsaihub.com](https://weeklyops.lxsaihub.com)

## Highlights

- 4-agent pipeline (collect, clean, analyze, report)
- Z-score + drift anomaly detection with cause candidates
- WoW and YoY change on every metric
- 4-sheet Excel export (Overview, Trend, Anomaly, Actions)
- Runs with no API key — deterministic by default
## What it does

Paste your weekly metrics (or load the sample) and a four-agent pipeline runs collect, clean, analyze, report. You get a four-sheet Excel workbook: Data Overview, Trend Analysis, Anomaly Annotation and Operations Recommendations, with WoW/YoY change, Z-score anomalies, root-cause candidates and P0/P1/P2 ranked actions. The deterministic pipeline works with no API key; model-assisted narration is optional.
